PROJECT CASE STUDY

DermaGlow AI Store

A full-stack AI skincare assistant combining semantic retrieval, Retrieval-Augmented Generation, conversation memory and cloud deployment.

FULL-STACK AI · RAG

AI-powered product discovery through natural conversation.

DermaGlow is a working AI-powered skincare storefront where users can ask questions naturally and receive relevant product recommendations.

The application combines a JavaScript frontend, FastAPI backend, semantic product retrieval, Gemini and conversation context.

AI WORKFLOW

What happens when a user asks a question?

01

User Query

The user asks a natural-language question about a skincare concern or product need.

02

Semantic Retrieval

The backend finds the most relevant products using embedding similarity.

03

RAG Context

Retrieved product information becomes the context supplied to Gemini.

04

AI Response

Gemini generates a response grounded in the retrieved product catalog.

05

Structured Data

The backend returns the natural-language reply together with product metadata.

06

Product Cards

JavaScript renders images, prices and View Product actions in the chatbot UI.
