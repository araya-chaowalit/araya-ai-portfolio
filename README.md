## Featured Projects
### IoT Network Behavior & Anomaly Detection

Research at the University of Victoria in collaboration with Optigo Networks, investigating how BACnet/IP traffic can reveal device behavior and unusual communications in building automation networks.

**Highlights**

- Analyzed protocol services, communication timing, and request/response patterns
- Engineered features to characterize device activity and communication behavior
- Investigated periodic, regular, and random traffic patterns
- Evaluated rule-based and machine learning approaches for device profiling and anomaly detection
- Developed a Device Behavior–Anomaly Detection Framework to connect behavioral analysis with anomaly investigation

Unusual behavior is an investigation signal, rather than confirmation of a cyberattack.

**Technology:** Python, BACnet/IP, Pandas, scikit-learn, Wireshark, feature engineering, clustering, anomaly detection

### Multilingual Trust \& Safety NLP

A Thai–English text-classification project that fine-tunes multilingual DistilBERT to identify potential off-platform communication and policy-violating intent.

**Highlights**

* Prepared and validated a highly imbalanced dataset of 3,044 messages
* Fine-tuned a multilingual Transformer for binary sequence classification
* Selected the decision threshold using validation data
* Evaluated the final model on a held-out test set
* Addressed privacy, model limitations, and the need for human review

**Held-out results:** 99.32% accuracy · 85.71% precision · 60.00% recall · 70.59% F1

**Technology:** Python, PyTorch, Hugging Face Transformers, DistilBERT, scikit-learn, Pandas

[Read Case Study](https://araya-chaowalit.github.io/araya-ai-portfolio/nlp-project.html) · [View Source Code](https://github.com/araya-chaowalit/multilingual-trust-safety-nlp)
